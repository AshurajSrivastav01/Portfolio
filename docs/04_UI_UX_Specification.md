# UI/UX Specification

Version: 1.0

Project: Ashuraj Srivastav Portfolio

---

# 1. Design Philosophy

The design should communicate professionalism, technical expertise, and trust.

The interface must feel clean, modern, and minimal while emphasizing readability and usability over decorative elements.

Inspired by:

- Laravel
- Vercel
- Linear
- Stripe
- GitHub

The website should look like a professional SaaS landing page rather than a generic developer portfolio.

---

# 2. Design Principles

Every design decision should follow these principles:

 Simplicity
 Consistency
 Accessibility
 Performance
 Readability
 Visual hierarchy
 Responsive design

Avoid unnecessary visual effects.
