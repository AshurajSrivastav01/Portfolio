# Content Strategy

Version: 1.0

Project: Ashuraj Srivastav Portfolio

---

# 1. Purpose

This document defines all website content, messaging, and copywriting guidelines.

The objective is to communicate professionalism, technical expertise, and trust while encouraging recruiters and potential clients to contact Ashuraj.

---

# 2. Brand Voice

The content should be:

- Professional
- Clear
- Confident
- Friendly
- Honest
- Solution-oriented

Avoid:

- Buzzwords without substance
- Exaggerated claims
- Overly casual language
